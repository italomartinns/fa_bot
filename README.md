# FA Bot

## Como executar
1. Instale as dependências:
```bash
npm install
```
2. Inicie o servidor local:
```bash
npm start
```
3. Abra a aplicação no navegador usando o endereço exibido no terminal.

## Observação
A aplicação foi preparada para funcionar com rotas de API separadas (n8n) e banco PostgreSQL em ambiente de produção.
